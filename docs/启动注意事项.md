# 启动注意事项

## Windows 下使用 CloakBrowser

当 `.env` 设置 `XIANYU_BROWSER_BACKEND=cloakbrowser` 时，CloakBrowser 会根据运行进程的系统与 CPU 架构选择浏览器二进制；正常的 Windows 64 位环境应识别为 `Windows-AMD64` 或 `Windows-x86_64`。

请从正常的用户终端启动服务：

```powershell
python -m app.main
```

不要通过“清空后只补少量变量”的方式启动后台 Python 进程。若遗漏 `PROCESSOR_ARCHITECTURE` 等系统变量，Python 可能将机器架构识别为空，CloakBrowser 会报错：

```text
Unsupported platform: Windows . Supported: ... Windows-AMD64, Windows-x86_64
```

此时 API 面板仍可能可以打开，但 Worker 无法初始化，队列项会保持排队状态且不会发送消息。

处理方法：停止该服务进程，并在保留完整 Windows 用户环境的终端中重新执行 `python -m app.main`。随后在面板点击“启动”验证 Worker；若仍失败，再检查当前终端中的 `PROCESSOR_ARCHITECTURE` 是否为 `AMD64`，以及 CloakBrowser 可选依赖和该后端的登录态是否已安装、生成。

## 其他启动前检查

- `.env` 的 `XIANYU_BROWSER_BACKEND` 与已安装的可选依赖一致。
- 用当前后端执行 `python scripts/login_xianyu.py`，生成独立登录态。
- 配置 `DEEPSEEK_API_KEY` 后再启动 AI 回复模式。
- 启动失败时，先核对错误信息；不要反复启动 Worker，以免误以为队列已经发送。
