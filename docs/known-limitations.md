# 已知限制与真机验收

## 已知限制

- 发送前若普通页面浮层遮挡发送按钮中心，工具会只读检查按钮内部多个点位；只要仍有实际命中发送按钮的可见区域，就在该区域完成唯一一次鼠标点击。它不会自动关闭浮层，也不会点击被遮挡区域；所有检查点都被遮挡时失败关闭。
- 执行一次发送点击后，只有从完整聊天记录读回同文且两秒后仍存在的“我”消息，才会标记为已发送；网络传输正文仅作附加审计，因为闲鱼可能加密或不暴露其载荷。本人消息未回读时会失败关闭且不会自动重试
- 闲鱼聊天可能在新标签页建立长连接；工具会在新页创建时开始监听 WebSocket，但若闲鱼改用加密且不含消息正文的载荷，仍会保守地报告“发送结果无法确认”
- 闲鱼会先渲染可撤销的本地发送气泡；工具会等待两秒并重新从完整消息列表确认该气泡仍存在，避免将本地临时状态误报为已发送
- 闲鱼 React 页面在点击聊天前可能短暂替换 `body` 节点；工具最多等待两秒主体稳定，超时仍失败关闭，不会跳过风险检查
- 长驻浏览器首次进入商品页时可能出现一次无副作用的导航重绘；工具只会重新打开该商品页一次。进入聊天会话后不再自动重试，以避免重复发送
- 发送确认后，闲鱼 React 可能让紧随其后的增量扫描短暂为空；工具仅在适配层已稳定确认本人消息时写入这条已确认记录，扫描出现其他内容却缺少本人消息仍会失败关闭
- 首轮发送后只监听本轮新出现的卖家回复；历史聊天中的旧卖家消息不触发下一轮。等待超时会暂挂，绝不会连续催发
- 等待卖家回复只按 2、3、5、8、12、15 秒的退避节奏读取当前聊天 DOM，不会为轮询执行整页刷新。
- 卖家监听不依赖后台浏览器的 WebSocket 推送；每个最长 5 秒的监听周期都会只读刷新绑定聊天页，再按消息在页面中的真实上下位置识别新增回复
- Worker 重启会优先恢复唯一的 `active` 会话；若恢复时页面身份或消息边界无法确认，仍会失败关闭且不补发消息

- 本工具会真实向卖家发送消息；请先用无所谓的测试商品联调
- 长时间挂着浏览器轮询聊天页有风控风险；退避会逐渐变疏
- 页面 DOM 变更可能导致打开聊天或发送失败，需重新标定选择器
- 同意/拒绝降价使用确定性正则，无法覆盖所有口语表达
- 进程退出后浏览器会话结束；队列状态在 SQLite 中保留，但聊天上下文需从页面重读
- 缺 `DEEPSEEK_API_KEY` 或登录态时，面板仍可入队，但 Worker 启动会失败
- MVP 面板为静态 HTML 短轮询，未使用 WebSocket

## 浏览器后端切换

AI Worker 默认 `XIANYU_BROWSER_BACKEND=chromium`，也可切换为 `camoufox` 或 `cloakbrowser`（需安装对应可选依赖）。各后端使用独立登录态文件，默认位于 `data/browser_states/{backend}_storage_state.json`；切换后端后应重新运行 `scripts/login_xianyu.py`，不要默认共用一份 storage_state。

**换浏览器不等于解决闲鱼封控。** 账号历史、操作频率、重复内容、登录环境变化、IP 与异常行为仍可能触发限制。工具不会在验证码或风控页后自动轮换浏览器继续操作；遇风险页仍立即停止。

## 真实 Edge / Chrome 调试会话（可选，仅手动模式）

默认 AI Worker 会按 `XIANYU_BROWSER_BACKEND` 启动独立浏览器并加载对应登录态。手动回复模式可在本机 `.env` 配置 `XIANYU_CDP_ENDPOINT=http://127.0.0.1:9222` 连接用户已经验证可正常发送的本机可见浏览器。该地址仅接受 `localhost`、`127.0.0.1` 或 `::1`；Worker 停止只会断开连接，不会关闭用户的浏览器。

新版 Edge 不会为默认资料目录开放远程调试端口；调试 Edge 必须以非默认的本地临时资料目录启动。资料目录与登录数据不得放入项目目录、Git 或日志中。

## 手动回复模式

- 面板选择“手动回复”后，下一条会话只会连接 `XIANYU_CDP_ENDPOINT` 指向的本机可见浏览器；未配置或无法连接时会失败关闭，不会退回独立 Chromium / CloakBrowser / Camoufox。
- 在该浏览器中由用户自行登录、完成平台验证并打开闲鱼；工具只在用户点击“确认发送”后提交一条文本，并等待页面确认。
- 手动模式不会自动生成开场白，也不会因卖家回复“可以”或“不能便宜”自动结束。手动结束该队列项后，Worker 才会处理下一家。

## 不做的事

- 自动购买、付款、填地址、确认收货
- Chrome 扩展
- 商城订单绑定 / 采购白名单
- 扫描无关私聊
- 遇风控后自动轮换浏览器继续操作

## 真机验收清单

1. `python -m pytest tests -q` 全绿
2. 确认 `.env` 中 `XIANYU_BROWSER_BACKEND`（默认 chromium；cloakbrowser 需先 `pip install -e ".[cloakbrowser]"`）
3. `python scripts/login_xianyu.py` 生成当前后端对应的登录态
4. 运行 `python scripts/print_account_fingerprint.py`，把输出写入 `XIANYU_EXPECTED_ACCOUNT_ID`
5. 配置 `DEEPSEEK_API_KEY` 后 `python -m app.main`
6. 面板贴 3 个测试链接，启动 Worker：只开第 1 家
7. 第 1 家超时后自动进第 2 家
8. 第 2 家若秒回，保持深聊，第 3 家仍排队
9. 深聊中再贴第 4 个：提示排在第 N，不打断
10. 点「优先插队」：当前结束，切到指定项
11. 卖家同意降价：状态 `done_agreed`，继续下一家
12. 任何「发送结果无法确认」必须人工打开闲鱼核对，禁止盲目重跑同一条
